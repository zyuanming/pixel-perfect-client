# Contributing

Thanks for improving `pixel-perfect-client`.

## Good contributions

- better visual measurement
- more robust screenshot normalization
- typography diagnostics
- platform screenshot adapters
- view/accessibility hierarchy inspection
- design-spec improvements
- examples from real client stacks
- Figma-optional design synchronization
- visual regression reporting

## Pull request expectations

For behavior changes, explain:

- problem
- approach
- before/after behavior
- compatibility impact
- test evidence

For schema changes, update relevant examples and docs.

For visual-diff changes, include sample metrics/artifacts or a deterministic test where possible.

## Scope

Avoid turning the project into:

- a generic app generator
- a Figma-only tool
- an iOS-only tool
- a game-engine UI framework
- a prompt dump with duplicated policies

The project should stay centered on measurable visual reconstruction and runtime validation.
